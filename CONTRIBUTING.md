# Contributing to Akra ADE

Akra ADE is source-available under the [Akra ADE Source License](LICENSE). It is not open source.

## What is welcome now

- Bug reports and suggestions in GitHub issues.
- Requests for permission that the license requires, such as redistribution. Open an issue and
  describe what you want to do. Permission is valid only when akra dev studio gives it in writing.

## Pull requests

External pull requests are not accepted yet. The contribution terms are not decided. Until they are
published here, a pull request from outside the project is closed without review.

## Your own extensions

Settings, repository extensions, skills, and other works that run with Akra ADE but do not contain
its source code are yours. The license does not restrict them.
