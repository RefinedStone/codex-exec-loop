# Akra Desktop 실환경 수동 검증표 (#2846)

상태: **미검증 (절차만 준비)**. 이 표의 동작은 단위 시험이나 Linux 화면 시험(xvfb)으로만 덮였다. 사람이 각 OS 에서
한 번씩 실행하고 "결과", "날짜", "SHA" 칸을 채운다. 발견한 결함은 따로 이슈로 뗀다. 창이 보이는 실행이므로 사용자가
직접 하거나 허락한 뒤에 한다.

- 기준: 출처 PR 들의 "확인하지 않은 것" 절 (아래 각 줄의 출처).
- 결과 칸: `통과`, `실패 (#이슈)`, `미검증 (이유)` 중 하나이다.
- SHA: 실행한 `prerelease` 커밋이다.
- 모델 턴: "턴" 열이 `예` 인 줄은 Codex 사용량을 쓴다. 실행 전에 따로 허락을 받는다 (plan 17 D-13).

## 준비

1. `npm --prefix desktop ci` 뒤 `npm --prefix desktop run dev` 로 Desktop 을 연다. Gateway 는 같은 PC 의 것을 쓴다.
2. 시험용 저장소 하나를 만든다: 커밋 두 개, 바뀐 파일 둘, 충돌 상태(`UU`) 파일 하나, 서브모듈 하나, 심볼릭 링크 하나.
3. Windows 는 화면 배율 100% 에서 시작한다.
