### 반려 근거

workspace_root+relative_path 키로 worktree가 분리되며 구형 baseline은 자동 채택하지 않는다. 재-export는 candidate를 덮어쓸 수 있으므로 편집본 보관이 필요하다. dirty candidate 보호와 자동 migration은 별도 전환/복구 정책으로 남기고 이번에 자동 덮어쓰기나 DB 키 회귀 수정에 섞지 않는다.

### 재검토 조건 — 추후 제안

재-export 전 백업/복사 안내와 dirty candidate 처리 UX를 별도 완료 기준으로 정할 때. 현재 사용자 편집본은 먼저 보관해야 한다.
