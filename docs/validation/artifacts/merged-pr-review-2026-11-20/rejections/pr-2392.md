### 반려 근거

현재 rename 이후 directory sync 실패는 새 문서 설치 가능성을 가진 Err다. 단계별 fault injection이나 불확실한 결과 상태를 추가하는 것은 별도 장애 계약이며 실제 재현이 없는 권고로 분류한다. 저장되지 않았다고 단정하지 말고 재조회해야 하며 이번 코드에서 원자 롤백을 추가하지 않는다. write_document의 fresh-home 호출자 주석 정리도 비차단 문구 개선으로 이번 수정 범위에서 제외한다.

### 재검토 조건 — 추후 제안

fsync 단계별 실패 재현과 catalog invalidation/재조회 결과 표현을 함께 설계할 때.
