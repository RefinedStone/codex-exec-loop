### 반려 근거

lexical 판정은 실제 .. 세그먼트·절대 경로만 거절하며 실제 대상 검증은 gitStatus의 descriptor/realpath 경계다. #2404의 FIFO 보완까지 이미 반영되었다. 새 경로 우회 재현이 없는 추가 조합은 이번 수정에서 확대하지 않는다.

### 재검토 조건(제안)

위 조건은 향후 재검토를 시작할 기준이며, 해당 개선의 구현 또는 검증이 완료되었음을 뜻하지 않는다.
