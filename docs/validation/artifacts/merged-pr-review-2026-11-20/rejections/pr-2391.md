### 반려 근거

현재 한도는 세션 RPC 하나이며 resident mutex 대기나 여러 RPC의 총시간이 아니다. 전체 사용자 요청 120초 보장과 admission 상한은 현재 계약에 없으므로 이번 수정에서 확대하지 않는다.

### 재검토 조건 — 추후 제안

UI/서비스가 전체 요청 기한을 약속하게 될 때 admission deadline·동시 요청 상한과 함께 구현.
