### 반려 근거

watch/take_until은 SSE body가 poll될 때 종료를 관찰한다. 기존 시험은 실제 꽉 찬 TCP 송신 버퍼까지 보장하지 않는다. 별도 소켓 최종 deadline 추가는 비재현 계약 확대라 이번 패치에 넣지 않으며 모든 비읽기 클라이언트 즉시 종료를 검증했다고 주장하지 않는다. 테스트의 무효한 CRLF replace 제거 제안은 동작에 영향 없는 정리이므로 이번 수정 범위에서 제외한다.
