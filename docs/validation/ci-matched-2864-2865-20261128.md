Both platforms used one Ryzen 9 7900X3D workstation (24 logical CPUs), without overlapping Windows and Linux timing samples. The machine was not reserved or load-isolated. The cache was not flushed. The small samples describe local spread, not a hosted p90, job median, or queue-time change.

## Windows portable contract (#2864)

The [original receipt](ci-native-process-wakeup-20261127.md) selects a real Git/SQLite contract from the expensive automatic-verification filter. The archived instrumented executables from that investigation were reused read-only. Their SHA-256 values were `747f45341f490f368ea1b09c540eef3c5ebb8f25236ee714ec0b896090756c1a` (baseline) and `c270bd7d368b30595e18544d909f8481b29a6e213e3aef82f04e402459e80618` (candidate). The historical build description specifies Rust 1.95.0, locked dependencies, all features, `x86_64-pc-windows-msvc`, and the default test profile. The historical baseline is `caf1da09aa561d1510b3271cc663b8e5bf3a0690` with test-only instrumentation; the candidate archive is from the process-wakeup investigation. These binaries were not freshly rebuilt from the later merge SHA, and no historical compiler-cache-hit claim is made. Compiler and link time are outside this comparison.

Extract `caf1da09aa561d1510b3271cc663b8e5bf3a0690` to a disposable directory. Run both executable variants from that same directory, with the same Windows Git `2.53.0.windows.1` and environment. The equivalent entrypoint is:

```powershell
$env:AKRA_NATIVE_TEST_TIMINGS = '1'
$test = 'application::service::parallel_mode::orchestrator_loop::tests::automatic_verification::automatic_verification_dispatch_epoch_closure_stops_before_run_and_refresh'
& $exe --list
& $exe --list --ignored
& $exe --exact $test --nocapture --test-threads=1
```

The exact test passed in every sample. Both lists retained the same 24 ignored names. The ordinary inventory increased from 6,418 to 6,419, with no removals and one addition: `subprocess::controlled::tests::cancellation_after_exit_signal_keeps_the_cancelled_fact`. The exact workload is matched, but the full Windows inventories are not identical. Both variants logged 510 Git preparations and 190 `command_output` events per sample. Median sums for `command_output` were 2.912 s and 2.372 s; Git preparation medians were 3.792 s and 3.679 s. These instrumented intervals can overlap and must not be added to obtain wall time.

## Linux architecture tests (#2865)

The [original Linux receipt](ci-linux-test-performance-2026-11-27.md) identified `shell_chrome_state_has_one_typed_reducer_writer` in a hosted slow-test warning. Both local harnesses read the complete extracted `ee762fb9e01e37abf8b3b40ad992bcf50dbde0c4` tree through the same `CARGO_MANIFEST_DIR`. Only the compiled architecture test file changes: baseline from that tree and candidate from `821c40068a9ce020bee39d191d81a352130d56ae`. This isolates the test-only registry change from production-tree drift.

Rust `1.95.0 (59807616e 2026-04-14)` built the shared dev dependencies once with `cargo generate-lockfile --offline` and `cargo build --locked --offline` in a standalone dependency crate with a fresh target, using the existing registry cache. Pin `syn=2.0.117` with `full`, `visit`, `visit-mut`; `quote=1.0.45`; `proc-macro2=1.0.106` with `span-locations`; and `unicode-ident=1.0.24`. Set `CARGO_INCREMENTAL=0`, with no compiler wrapper or custom Rust flags. Use the resulting rlibs for both builds:

```bash
export CARGO_MANIFEST_DIR="$PWD/linux-input"
for variant in linux-input linux-candidate; do
    rustc --test --edition=2024 -C debuginfo=1 -L "dependency=$deps" \
        --extern "syn=$syn" --extern "quote=$quote" --extern "proc_macro2=$proc_macro2" \
        "$variant/tests/architecture_boundaries.rs" -o "$variant.bin"
done
```

Run each binary from `linux-input` with `--list`, `--list --ignored`, `--exact shell_chrome_state_has_one_typed_reducer_writer --test-threads=1`, and `--test-threads=4`. Inventory lists matched byte-for-byte (SHA-256 `8506ba81de402101544b3668671338590b8ec003b8c0f485d8b5579d0aba394c`); ignored lists also matched. Each suite run passed all 150 tests with 0 failed and 0 ignored. This comparison does not time the root libtest or the hosted Rust Tests job.
