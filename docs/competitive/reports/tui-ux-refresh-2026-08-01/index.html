DEFINITION OF DONE

상용 수준을 판단할 검증 계약

화면이 예뻐졌다는 평가는 충분하지 않다. 각 slice는 상태 authority, 실제 키, 폭, 물리 터미널 증거를 함께 통과해야 한다.

01

Semantic fixture

READY/OFF/EMPTY/BLOCKED 조합별 snapshot에서 모순 문구가 없어야 한다.

02

Width contract

80·120·160열에서 핵심 action이 남고 중요도가 낮은 detail부터 줄어든다.

03

Input truth

화면에 보이는 모든 키는 실제 handler와 동일하며 비활성 키는 숨거나 LOCKED다.

04

ConPTY / PTY capture

실패·복구·resize 후 stale row, scrollback 손실, clipped action이 없어야 한다.

05

Authority boundary

renderer가 상태를 추측하지 않고 application read model을 배치만 해야 한다.

06
