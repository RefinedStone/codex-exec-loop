CROSS-PRODUCT ARCHITECTURE AUDIT / 2026.07

Coding-agent TUI는
어떻게 복잡성을 통제하는가

GJC, OpenCode, Codex, Claude Code, Pi, jcode의 최신 공식 소스와 릴리스 아티팩트를 비교했다. 결론은 “좋은 프레임워크를 고르면 버그가 사라진다”가 아니다. 권위 상태, 화면 projection, terminal delivery를 분리하고 실패를 재구성 가능하게 만드는 제품이 더 안정적이다.

Akra의 다음 경계: TUI가 원장을 복사해 운영하지 않게 한다.

01

FALSE PREMISE

버그 없는 경쟁 앱은 없다

공식 changelog와 tracker 모두 resize, stale frame, rewind race, queue duplication, CJK 정렬 회귀를 기록한다.

02

REAL LEVER

언어보다 경계가 중요하다

Rust도 거대 mutable App을 만들고, React도 stale projection을 만든다. typed correlation과 단일 mutation gate가 차이를 만든다.

03

AKRA PRIORITY

프레임워크 교체는 P0가 아니다

먼저 authority ack 이후에만 projection을 갱신하고, terminal frame을 semantic state에서 재구성 가능하게 만든다.

근거 분류 근거 원장과 부채 항목은 아래 등급을 표시한다. 아키텍처 도식·비교표·Akra 결정은 그 원장을 종합한 분석이며 claim별 검증 배지가 아니다.

02 / AUTHORITY & STATE FLOW

제품별 아키텍처 해부

authority, projection, renderer, extension, 검증 방식을 모든 제품에 같은 축으로 적용했다.

03 / RENDERER LEDGER

무엇으로 그리는가

동일한 “TUI”라도 component tree, frame diff, scrollback 소유 방식이 다르다.

제품 UI / layout 권위 상태 frame 전략 mouse terminal QA 확장 경계

정성 분류이며 성능 순위가 아니다. “강함”은 공개 근거의 밀도와 해당 경계의 명시성을 뜻한다.

04 / WHY IT FEELS WEB-LIKE

웹처럼 매끄러운 이유

시각적 완성도는 한 라이브러리가 아니라 여섯 개의 반복 가능한 시스템에서 나온다.

공식 시각 자료

표현 수준을 확인하는 자료일 뿐, 성능·정확성·현재 기본 활성화를 증명하지 않는다.

05 / OPENCODE UNDO, TECHNICALLY

마우스 Undo에서 배울 것

      08 / DECISION REGISTER

      Akra 실행 우선순위

      경쟁 기능 복제가 아니라 Akra의 Codex-first 운영·delivery 강점을 더 안전하게 보이게 하는 순서다.

      ADOPT

      가져올 것

      • Codex의 pending operation + base thread guard + authoritative ack
      • OpenCode의 row action menu + 좁은 undo dock
      • jcode의 정보 priority / minimum height / 좁은 화면 소멸 규칙
      • Pi·GJC의 virtual terminal, CJK, resize, replay regression
      • Claude fullscreen의 semantic transcript와 visible viewport 분리

      REJECT

      가져오지 않을 것

      • OpenCode식 fire-and-forget mutation과 optimistic composer 변경
      • 새 custom TUI framework 또는 React/OpenTUI 전면 migration
      • Pi·GJC식 거대 InteractiveMode coordinator
      • jcode식 local/remote rewind 이중 구현과 pending boolean 보정
      • 전체 transcript를 TUI가 별도 authority로 소유하는 구조

      DEFER

      뒤로 미룰 것

      • 대화 rewind / code rollback 자체
      • third-party TUI component plugin API
      • custom scrollback 전면 도입
      • desktop/web UI와의 기능 동등성
      • 테마 marketplace와 시각 customization

      09 / EVIDENCE LEDGER

      근거 원장
