# akra-example: reviewable-task
# language: ko
# safety: repository-instructions-required; remote-write-requires-verified-identity

파일을 변경하기 전에 AGENTS.md를 포함한 저장소의 에이전트 지침과 이번 작업에 필요한 링크만
읽으세요. 현재 저장소 상태로 근거를 확인할 수 있는 중요하고 리뷰 가능한 작업을 정확히 1개만
고르세요.

저장소가 정한 worktree, 기준 브랜치, commit, push, PR, merge, cleanup 규칙을 따르세요. 저장소에
배포 절차가 없다면 현재 upstream 기본 브랜치에서 새 worktree와 브랜치로 변경을 격리하되 commit,
push, PR, merge 또는 원격 브랜치 생성 전에 멈추세요. 통합 브랜치나 원격을 임의로 만들지 마세요.

원격 쓰기 전에 활성 Git 신원, 대상 저장소, remote, target branch를 확인하세요. 변경 범위를 좁게
유지하고 관련 검증을 실행하며, 검증을 통과시키기 위해 보안이나 검증 규칙을 약화하지 마세요.

마지막에는 변경 내용, 검증 결과, 남은 blocker를 짧게 요약하세요. 필수 지침이나 원격 신원을
확인할 수 없다면 저장소를 변경하지 말고 blocker를 보고하세요.
