# Bundled Admin Font

The admin UI bundles Galmuri 11 regular and bold from the upstream `v2.40.3`
release so Korean labels render offline under the strict content security policy.

- Source: `https://github.com/quiple/galmuri`
- License: SIL Open Font License 1.1 (`LICENSE-Galmuri.txt`)
- `Galmuri11.woff2`: `bb5655930587f2e3a2eb943afff42e39d9dc489a58df45a5fd524a9fd2178e90`
- `Galmuri11-Bold.woff2`: `03edc70cfacc32ec4d5d356ca2dbd9ff3fea92d08d6924eb8ace3b8b42336cb6`

Do not replace these files from an unpinned CDN URL. Update the version, hashes,
license copy, static asset tests, and browser capture together.
