381 failures in pool-reconciliation fixtures. An isolated failing test,
`completed_quarantine_does_not_block_the_same_source_normalization_recovery`, fails identically
on the unmodified origin/prerelease checkout before validator code is involved:

  git worktree add --detach \\?\C:\...\akra-pool\slot-1 prerelease

The validator branch changes the shared parallel test entry point only by adding the three
PR-validation test modules. The required Windows native PR gate above passes, and the failure is
therefore recorded as a pre-existing local Git extended-path harness limitation rather than a
validator regression.
